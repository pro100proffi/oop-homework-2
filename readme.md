# Исправление замечаний к домашнему заданию № 1

Проект взят из первой домашней работы и приведён в соответствие с полученным отзывом.

## Что исправлено

- В `User`, `Contact` и `CommunicationChannel` добавлены деконструкторы.
- `UserProfile.Contacts` возвращает одну заранее созданную read-only оболочку, а не создаёт новую при каждом обращении.
- `Contact` хранит `ChannelId`, а не ссылку на `CommunicationChannel`.
- В конструкторы и изменяемые свойства добавлена проверка пустых идентификаторов, строк и некорректных значений.
- Повторный контакт определяется по паре `(ChannelId, Value)` и не добавляется в профиль.
- Хэширование пароля вынесено из сервиса профилей в `IPasswordHasher`; реализация использует PBKDF2, соль и проверку в постоянное время.
